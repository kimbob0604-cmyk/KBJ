## 0. KIS 관례 재현 검사 (PLAN §6.2 1·2줄 — 2026-09-28 사용자 결정)

자체 `core.black76`·`core.greeks`(Black-76, r = 0)에 KIS 가 쓰는 입력을 넣어 KIS `delta_val`·`gama` 를
다시 낸다. 목적은 자체 공식 구현의 검증이다. 입력 관례는 가정하지 않고, 후보를 하나씩 바꿔 가며 두
스냅샷에서 가장 잘 맞는 것을 골랐다. 그 결과를 metrics §1.7 에 함수 명세로 옮겼다.

- 오차(판정 — 사용자 결정): 평이 상대오차 `(자체 − KIS)/|KIS|`(크기 `|자체/KIS − 1|`, 부호 자체 − KIS).
  허용 1% [확인 필요]. 범위: ATM±5(S_ref 기준)와 KIS 값이 있는 전체 행(KIS 0 = 값 없음은 뺀다)
- 반올림 보정 오차([확인 필요] 제안 — 판정 아님, 나란히 센다): KIS 값이 소수 4자리라 반올림
  구간(±0.00005) 밖으로 벗어난 만큼 / |KIS|. 작은 KIS 값은 반올림 폭만으로 1% 를 넘을 수 있다(감마
  0.0029 ±1.7%, 0.0011 ±4.5%, 0.0002 ±25%, 델타 0.0016 ±3.1%). 실측에서 이것이 문제 되는 곳은 ATM±5 가
  아니다 — 월물 ATM±5 는 평이 1% 로 22/22 다. ATM±5 밖의 작은 값(날개 감마, 깊은 콜 델타, 202611
  감마 0.0006~0.0011)이다(§0.2)
- 실패 원인: 평이 1% 밖 행이 반올림 보정으로는 1% 안이면 `반올림`(1% 를 넘은 몫이 반올림 폭 안 — 입력은
  맞다). 아니면 KIS Δ·Γ 한 쌍이 함의하는 (S*, x* = σ√T)로 입력을 바꿔 반올림 보정 1% 안에 드는지 본다 —
  S 만 바꿔 들면 `S`, σ 만 x*/√T_KIS 로 바꿔 들면 `σ√T`, 둘 다 바꿔야 하면 `S+σ√T`, 한 쌍을 못 풀면
  (Δ 0.02~0.98 밖·Γ 0) `풀이 없음`
