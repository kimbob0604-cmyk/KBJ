### 1.3 신고가 엔진 (`board/engine/newhigh.py`)

- **3종 신고가** — 60일(직전 60영업일) · 52주(252영업일) · 역사적(상장 이후 전체).
  20일은 뺐다(D-071)
- **종가 기준 / 고가 기준을 둘 다 계산**해 별도 컬럼에 저장. 리포트 기본값은 고가 기준
- **라벨 우선순위** 역사적 > 52주 > 60일. 상위가 하위를 포함
- **신규 / 이어감** — 직전 영업일에 같은 라벨이 없었으면 신규
- **근접** — 갭 5% 이내 + 시총 1,000억 이상
- **보드 하한** — 시총 1,000억 미만은 **생성 단계에서** 뺀다(D-072). 화면 필터가
  아니라 `newhigh.json` 을 만들 때 거르므로 엑셀·텔레그램도 같은 목록을 쓴다.
  하한 미달(회색)과 시총을 못 받은 것(빨강)을 따로 세어 배너에 나눠 싣는다
- **종목 종류** — 보통주 / 우선주 / 스팩 / 리츠 (`engine/kinds.py`). 빼지 않고 표시만
  붙여 화면에서 끈다. 우선주는 코드 끝자리와 이름이 둘 다 맞을 때만 단정한다(D-069)
- **5일 축소폭** — 현재 갭 − 5영업일 전 갭. 음수일수록 빠르게 좁혀짐
- **저항두께** — 현재가~기준 최고가 구간 누적 거래량 ÷ 20일 평균 거래량 (종가 기준, D-005)
- **거래량 배수** — 당일 거래량 ÷ 직전 20영업일 평균 (당일 제외, D-006)
- **수정주가 가드** — 하루 ±31% 초과 점프를 감지해 역사적 판정에서 빼고 룩백 창을
  점프 이후로 절단(D-001). `refresh_suspects()` 가 의심 종목 시계열을 다시 받아 덮는다
- 역사적 최고가는 `hi`(당일 포함)·`prev_hi`(직전일까지) 스칼라로 저장, 판정은 `prev_hi`(D-008)

종목코드 하나로 엑셀 리포트를 만든다. `python run.py --stock 006110`

### 3.1 블록

| 모듈 | 내용 |
|---|---|
| `statements.py` | 재무제표 수집 + **누적→분기 환산**(DART 손익계산서는 누적이라 차분으로 만든다) |
| `costs.py` | 공시원문 주석의 '비용의 성격별 분류' 를 파싱해 **7개 버킷**으로 접는다 |
| `bridge.py` | 영업이익 → 세전이익 → 법인세 → 순이익 **워터폴 브릿지**. 영업외손익 분해는 주석에서 |
| `orders.py` | 수주(단일판매·공급계약체결) 공시 수집·파싱 — 계약금액/상대/기간/내용 |

### 3.2 파서가 실제로 넘는 함정 (전부 실데이터로 잡은 것)

- **단위 배율** — `단위: 백만원` 이 표 밖에 있을 때와 표 안 캡션 셀에 있을 때를 모두 처리
- **누적 열 선택** — 분기 주석 표는 3개월치가 첫 숫자 열, 누적이 뒤. 머리말의
  `누적`/`누계` 로 찾고 두 줄 colspan 머리말도 해석한다
- **각주·숨은 합계 행** — 값이 나머지 합과 0.5% 안에서 같으면 합계로 보고 뺀다
- **rowspan 이 삼킨 라벨** · 40자 넘는 라벨 거부
- **연결/별도 파일 선택** — 공시 ZIP 안에 본문·연결감사보고서·별도감사보고서가 각각
  같은 주석 표를 갖고 있어 그냥 합치면 2~3중 계상된다. 기대값
  (매출−영업이익 / 세전−영업이익)에 가장 가까운 **파일 하나만** 고른다
- **검산 출력** — 매 실행마다 역산 영업이익 vs 공시 영업이익을 찍는다.
  실측: 006110 전 기간 ±0.0억 · 005930 연간 ±0.0억, 미매핑 항목 0~1건

### 3.3 진단 모드

`--diagnose-costs` 비용 매핑 튜닝 / `--diagnose-bridge` 영업외손익 표 덤프
매핑 동의어는 `config/mapping.yaml` 로 뺐다 — 코드를 고치지 않고 회사별 표기를 흡수한다

| `pages.yml` 대시보드 배포 | 푸시 시 | GitHub Pages 배포 |

전부 `workflow_dispatch` 로 수동 실행 가능하고 모드·종목코드 등을 입력으로 받는다.
GitHub 크론은 30~90분 지연되는 일이 잦다(실측: 16:00 예약분 21:08 실행) — 정시 보장이
필요한 작업은 이 위에 얹지 않는다.

**자격증명은 전부 GitHub Secrets 에만 있다.** 코드·로그·리포트 어디에도 값이 남지 않고,
`ingest/http.py` 의 `scrub()` 가 예외 메시지에서까지 지운다.
