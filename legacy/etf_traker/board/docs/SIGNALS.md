# 스윙 시그널

장 마감 확정값으로 **다음 거래일에 볼 종목과 가격**을 골라 텔레그램으로 보낸다.
보드(신고가·섹터 리포트)와 따로 가는 한 통이다. 결정 근거는 `DECISIONS.md` D-NEXT-S.

## 1. 먼저 읽을 것

- 규칙의 출처는 『유명 트레이더 매매법』(2026-09-23 판)이다. 그 문서가 스스로 적은
  대로 **성과를 검증한 자료가 아니다.** 여기 고른 조합도 백테스트 전 후보 규칙이다.
- 값마다 근거의 두께가 다르다. `config/signals.yaml` 이 값마다 표시를 단다.

| 표시 | 뜻 | 대응 |
|---|---|---|
| 원문 | 원문 본문에 숫자로 적힌 값 | 그대로 |
| [복원] | 원전에 값이 없어 그 문서가 채운 값 | 범위 안에서 바꿔 가며 확인 |
| [2차] | 남이 요약한 글의 값 | 원전 대조 전에는 그 사람 성과라 부르지 않는다 |
| 비원전 | 그 문서가 "원전값이 아니다" 라고 밝힌 값 | 격자 대상 |
| 새정의 | 원문에 없어 **이 저장소가 정한** 프록시 | 원작의 규칙이 아니다 |

- 원문의 '자동화 불가능' 항목은 쓰지 않았다. 쓴 것은 '가능'·'퀀트' 항목뿐이다.

## 2. 무엇을 보내나

```
스윙 시그널 — 기준일
시장: 코스피 / 60일선 위·아래 · 코스닥 / 120일선 위·아래      ← F9
52주 신저가 비율 x% (5일 전 y%)                                  ← F9
■ 돌파 확인 (N)                                                  ← F1+F3+F4, 태그 F2·F7
■ 돌파 감시 (N)                                                  ← 근접+F2+F3+F4, 태그 F7
결손 · 고지
```

한 종목 세 줄: ① 통과한 것(가격·등락·라벨·RS·거래량) ② 다음 날 쓸 가격
(돌파가·손절·목표·최대 비중) ③ 태그. 태그는 **거르지 않은 조건**이다.

## 7. 실행

```bash
python3 -m board.run --signals           # 지수 일봉·후보 수급을 받고 signals.json 을 쓴다
python3 -m board.run --signals --dry-run # 네트워크 없이 이미 받은 파일로만 다시 계산
python3 -m board.run --send signals      # 텔레그램 발송
```

```bash
python3 -m board.run --backtest          # 과거 날짜마다 같은 판정을 다시 세워 거래로 굴린다 → state/backtest.json
python3 -m board.run --send backtest     # 요약을 텔레그램으로
```

백테스트는 손으로만 돈다(Actions 모드 `backtest`). 규칙은 `engine/backtest.py` 머리말 —
d일 종가 판정 → d+1 체결, #42 청산(손절 −8% · 목표에서 절반 · 나머지 20일선 이탈 ·
목표 전 15영업일 시간 청산), 매도 0.35% + 편도 슬리피지, 상한가 갭 제외. **대조군**
(필터 없는 52주 신고가 전체)을 같은 청산으로 함께 돌려 필터가 값을 더하는지 본다.
라이브와 다른 점(과거 시총 없음 · 52주만 · 현재 이름 기준 구분 · 수급 없음)은 결과에 적힌다.

**페이퍼 장부** (`engine/ledger.py`, `state/signal_ledger.json`) — `--signals` 가 돌 때마다
그날 신호를 쌓고, 지난 신호를 **신호 뒤에 나온 실제 가격**으로 백테스트와 같은 규칙으로
채점한다. 표본 밖 성적이 여기서만 나온다. 줄마다 그날 규칙의 지문(`rules`)을 적어,
설정을 바꾼 뒤의 줄과 앞의 줄을 섞어 읽지 않게 한다. 상태: `pending`(다음 거래일 전) ·
`open`(보유 중, 종가 평가) · `closed` · `void`(상한가 갭·미체결 — 거래가 아니다).
메시지 끝 '■ 페이퍼 누적' 줄이 이 장부의 요약이다.

GitHub Actions `daily` 사슬 맨 끝에서 돈다. 실패해도 보드·파일 발송은 이미 끝났고
잡은 경고만 남긴다. 따로 돌리려면 모드 `signals`.

산출 파일 (`state/YYYYMMDD/`)

| 파일 | 내용 |
|---|---|
| `index_hist.json` | 코스피·코스닥 지수 종가 (평균선용, 네이버) |
| `signal_flows.json` | stockflows.json 에 없는 후보의 종목별 수급 (KIS → 네이버 폴백) |
| `signals.json` | 게이트·돌파·감시·결손·페이퍼 요약. `source`·`as_of` 를 머리에 싣는다 |
| `../signal_ledger.json` | state 루트. 페이퍼 장부 — 날짜와 무관하게 쌓인다 |

- 기준을 결과에 맞춰 낮추면 같은 표본에 맞춘 선택이 된다. 기준은 그대로 두었다.
