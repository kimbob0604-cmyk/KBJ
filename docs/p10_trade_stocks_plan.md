## 1. 단계

### 단계 1 — 종목별 흐름 화면 + 매핑 '흐름' 스키마 (국내 데이터만)

- `trade_map.yaml` 판 2: 종목 → `flows:` 목록. 흐름 = {이름, 국가 KR, 방향 exp/imp, 시군구 목록, HS6(또는 HS10) 묶음 + 제품명,
  상대국(비면 전세계), 구분(회사 출하/업황 혼합/관계사 혼입), 근거(DART 접수번호 + 자체 요약 문장), 가중치}.
  판 1 의 items·regions 는 흐름으로 옮긴다(해석기는 두 판 다 읽고, 판 1 은 '전국 품목 흐름' 하나로 본다).
- 페이지 7 맨 앞에 **'종목' 탭**(지금 품목 탭 아래 표를 끌어올린다) + 종목 하나를 고르면:
  흐름 카드(국가·시군구·품목명·상대국·구분·기준월·근거 접기) → 흐름별 월 차트(금액 막대 + YoY 라인, 서브 탭
  금액/단가 · 중량 · 일평균) → 월 표 + CSV → 페이지 8(주가·재무·컨센서스·overlay) 바로가기.
- 공개판: HS 숫자를 숨기지 않는다(관세청 공개 데이터·자체 매핑이라 숨길 이유 없음). 관심종목 전용 매핑(local)은 지금처럼 로그인판만.

### 단계 2 — 매핑 넓히기 + 맵핑 트렌드

- 후보 생성 도구(로그인 VM 에서 돌림): DART 사업보고서의 주요 제품·매출 구성·사업장 소재지 → (시군구, HS6 후보, 제품명)
  초안을 만들고 사람이 검토해 reviewed: true. HS 후보는 제품명 → HS 사전(`hs_chapters.yaml` 확장)으로 고르고, 지어내지 않는다.
- 검증: 흐름마다 과거 분기 매출과의 상관(overlay 엔진 그대로) — 낮으면 '업황 혼합'으로 표시.
- **'맵핑 트렌드' 탭**: 매핑 종목 전부를 최신월 흐름 YoY·3개월 YoY·단가 YoY 로 정렬, 급등락만 보기, 산업 칩 필터.
- **[결정]** 범위: 수출 비중 큰 약 300종목 / 관심종목 먼저 / 둘 다(관심종목 먼저 → 300).

### 단계 3 — 실적 프리뷰(국내)

- 종목마다: 흐름 월 수출(원화 환산) → 분기 누적(진행 중 분기는 10일 속보·일평균으로 남은 날 채움, 'EST' 표시) →
  과거 분기 매출과 회귀(시차는 overlay 가 고른 값) → **이번 분기 매출 추정** vs 컨센서스 → IN LINE / BEAT / MISS(문턱 [제안] ±5%).
- 화면: 페이지 8 에 '실적 프리뷰' 카드(비교표 + Rev 분기 점 차트 ACT·EST·KBJ 추정 + 상관 r·방향). 문장은 규칙 템플릿(LLM 아님).
- 알림: 매월 1·11·21일(10일 속보)·15일(월 확정) 뒤 판정이 바뀐 종목만 텔레그램 한 통.

### 단계 4 — 국가별 조회·산업 보강

- 국가 탭: 품목 행에 관련 종목·MoM·24개월 스파크라인, 품목 상세에 상대국 스택·최신월 도넛.
- **'산업' 탭**: 산업 → HS 묶음 → 종목. 산업 합산 월·10일 수출, YoY, 단가·물량 분해, 국가 비중.

### 단계 5 — 대만 월매출 (선택)

- 대만 상장사 월매출(거래소 공개 오픈 API — 공개 등급 여부·한도는 실측 [확인 필요]). 카드(최신월 YoY + 미니 차트)·표·업종 칩.
  반도체·전자 공급망 선행지표로 국내 종목 흐름 옆에 붙인다. 일본 월매출은 회사별 공시라 범위가 커서 뒤로.
- **[결정]** 넣을지.

### 단계 6 — 품목별 시장 점유율 (선택, 가장 큼)

- 수입국 통계(미국·EU·일본·중국 …)를 품목 단위로 받아 '한국 수출 ÷ 그 시장 전체 수입'. 나라마다 원천·한도·발표 시차가 달라
  나라 하나씩(미국 먼저) 실측부터. **[결정]** 넣을지·어느 나라부터.

## 2. 지키는 것

- 원천 데이터는 관세청(공개 — 이용허락 제한 없음)·DART·KIS(컨센서스 — 로그인판만). 나쁜양파 데이터·리포트는 쓰지 않는다(구조만 참고).
- 매핑 가중치·HS 는 근거(DART 접수번호)가 있어야 reviewed: true. 추정치는 화면에 '추정'·'EST' 로 구분.
- 실적 프리뷰는 매매 권유가 아니라는 문구를 붙인다.
