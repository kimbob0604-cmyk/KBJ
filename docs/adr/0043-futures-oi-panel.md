# ADR 0043 — 코스피200 선물 미결제약정(OI) 패널: 페이지 3·합계 OI 기준·기존 원천만·잠정 표시 (2026-10-27)

상태: **제안**(사용자가 맥에서 화면을 확인하면 확정). 근거: 사용자 요청(2026-10-27 — 18시 '국장 신고가' 정리에서
"외국인 선물 순매수가 신규 매수인지 숏 커버인지" 판별 근거. 2026-10-26 외국인 코스피200 선물 +3,451계약 3거래일 연속
매수였으나 미결제약정 미확인이라 판별 불가), metrics §33(정본 정의), ADR 0036(KRX 파생 일별·전광판 수집), ADR 0019
(`investor_flow` 쓰기 주인), DATA_TIERS(KRX·KIS = 로그인).
구현: 엔진 `kbj/engines/gex/futures_oi.py`, 저장소 `PgGexRepo`·`MemoryGexRepo` 의 `krx_futures_days`·`investor_closes`,
리더 `kbj/services/api/readers/gex_oi.py`, 라우트 `GET /api/gex/futures-oi?days=`(모델 `FuturesOi`), 캐시 영역 `gex_oi`,
화면 `web/src/pages/p3/oi.ts`(페이지 3 ⑤ — GEX 아래, 이벤트 위).

## 1. 맥락

- 필요한 원천은 이미 다 수집된다: KRX 선물 일별 OI(`prv_gex.krx_fut_daily.acc_opnint_qty` — `gex.krx_derivatives`, 평일
  08:05 전 거래일분), KIS 선물 전광판 장중 OI(`prv_gex.fut_board.oi` — `gex.poller`), 장중 투자자별 파생 수급
  (`prv_gex.investor_flow` — `flows.market_minute`, K2I 선물·월물 콜/풋, 위클리 콜/풋). 새 외부 수집기는 필요 없다.
- KRX 확정 OI 는 **다음 날 아침**에 온다. 18시 정리 때 오늘 OI 는 전광판 잠정값뿐이다.
- `flows.market_minute` 은 현물 마감 + 10분(15:40)까지만 돈다. 선물은 15:45 에 끝나(15:35~ 종가 단일가) 그날 마지막
  행이 선물 확정 누적과 다를 수 있다.

## 2. 결정

1. **위치 — 페이지 3(진단), GEX 패널 아래·이벤트 위.** 페이지 3 은 이미 파생 포지셔닝(GEX — KIS 옵션 체인·선물 전광판)과
   수급 진단(외국인 현물 + K200 선물 20일 — §D6)을 보여 주고, 같은 로그인 갈림(공개 빌드는 자물쇠·요청 0, 본문 번들 제외)
   을 쓴다. 페이지 1(시장)은 현물 장중 흐름(분 단위 투자자·프로그램) 화면이라, 하루 한 번 바뀌는 일별 파생 포지션
   시계열은 진단 쪽이 맞다. 라우트도 `/api/gex/*`(파생 영역 — 같은 `prv_gex` 표) 아래에 둔다.
2. **OI 기준 — 전 월물 합계.** 근월물만 보면 롤오버 주간(만기 전 주)에 OI 가 다음 월물로 옮겨 가 '롱 청산'처럼 보이고,
   외국인 순매수(F001)는 전 월물 합이라 범위가 어긋난다. 근월물 OI 는 참고 칸으로 같이 싣는다.
3. **롤오버·만기** — 근월물은 '그날 마감 뒤에도 살아 있는 가장 가까운 월물'(만기일엔 다음 월물). 라벨에 쓰는 OI 증감은
   그날 행이 있는 종목끼리의 증감: 만기 다음 날 사라진 만기 종목(최종결제 소멸분)은 양쪽에서 빠지고, 만기일 행은 KRX OI 가
   0 보다 크면 넣고 0 이면 뺀다 [확인 필요 — 만기일 OI 실측]. 처음 안(만기일에 만기 종목을 통째로 빼기)은 합성 시험에서
   만기일 롤 매수(차월물 증가)만 남아 '신규 매수'로 잘못 읽혀 버렸다. 단순 차는 표시만.
4. **라벨 — 규칙 넷 + 보합·판단 불가.** 임계 가격 0.10%·OI 0.30%는 기본값 [확인 필요]. 엔진 상수로 두고 응답에 싣는다.
5. **잠정** — KRX 확정 전 오늘은 전광판 합계로 잠정 행(estimated). 만기일·만기 다음 날은 라벨 보류, 전광판 합계가 전일
   기준 ±20% 밖이면 invalid(행 구성 실측 전 안전장치).
6. **투자자 일별** — `investor_flow` 그날 정규장 마지막 행. 15:45 전 행이면 estimated + 사유(위 1의 한계). 옵션 투자자
   일별(월물·위클리 콜/풋 순매수)도 같은 원천이라 같은 응답·같은 패널에 싣는다.
7. **캐시 영역 `gex_oi`** — 작업 `gex.krx_derivatives`·`flows.market_minute` + `prv_gex.fut_board` 최신 시각. GEX 영역
   (엔진 사이클 시각)에 넣으면 장 밖에 KRX 일별이 들어와도 버전이 안 바뀐다.

## 3. 결과·남은 것

- 18시 정리: 확정 행(어제까지) + 오늘 잠정 행(전광판 OI·투자자 15:40 행)으로 라벨을 본다. 확정은 다음 날 08:05 뒤.
- [확인 필요] FHPIF05030200 행 구성(스프레드·미니 포함 여부)과 KIS 장중 OI 가 실시간 값인지 — 실측 뒤 구성 검사 문턱을 고친다.
- [확인 필요] 선물 투자자 마감 누적: `flows.market_minute` 에 파생 조합만 15:55 까지 한 번 더 받는 슬롯을 두면 estimated 가
  풀린다(작업 일정 변경 — 이 ADR 범위 밖, 사용자 결정).
- 임계값(0.10%·0.30%)은 몇 주 운영 뒤 분포를 보고 정한다.
