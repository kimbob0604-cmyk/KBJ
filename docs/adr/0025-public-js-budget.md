# ADR 0025 — 공개 JS 예산 60 → 72 KB(페이지 7 수출입은 공개 전체) (2026-10-13)

상태: **채택**(2026-10-13 — 사용자 결정: 설계서 열린 질문 Q1 기본값 채택, P6 웨이브 3 WRAP).
근거: `docs/p6_design.md` §1.6 6·§9 R1·R3·§10 Q1, `docs/DATA_TIERS.md` §2(페이지 7 = 공개 전체), ADR 0008(웹 셸·번들 검사).
구현: `web/scripts/check-bundle.mjs`(`BUDGET_GZIP.public.js`), `web/test/scripts.test.ts`.

## 1. 맥락

- 공개 빌드 JS gzip 예산은 P3 에서 60 KB 로 정했다(`check-bundle.mjs` — 모든 청크 합, `sw.js` 제외). P5·IDX 까지 로그인
  본문을 공개 번들에서 빼는 방식(`LOGIN_VALUE` 등)으로 버텨 IDX 뒤 61,217 B(남은 것 약 0.2 KB)였다.
- 페이지 7(수출입 — 속보·품목·국가·지역·급등·104품목, CSV)은 **전부 공개**라 로그인 분리로 줄일 수 없다. 페이지 8
  '수출 겹쳐 보기'도 공개 패널이다(로그인 월말 종가 줄만 빠진다).

## 2. 결정

1. 공개 JS gzip 예산을 **72 KB(73,728 B)** 로 올린다. CSS 20 KB·로그인 JS 90 KB 는 그대로.
2. 로그인 전용 줄은 계속 공개 번들에서 뺀다 — P6 는 `p8/trade_overlay_price.ts`(`LOGIN_TRADE`). 공개 번들 금지 문자열에
   '월말 종가'를 더해 빠졌는지 빌드마다 본다.
3. 예산을 다시 넘으면 먼저 공개 패널의 차트 부품을 나눠 쓰는지(중복) 보고, 그다음 페이지 7 의 트리맵·단가 대 물량 차트를
   로그인으로 옮기는 안(R1 대안)을 사용자에게 묻는다 — 예산을 조용히 올리지 않는다.

## 3. 결과

- P6 WRAP 빌드(2026-10-13): 공개 JS gzip **73,088 B**(예산 73,728 — 남은 것 약 0.6 KB), 로그인 91,182 B(예산 92,160 — 약 1 KB).
  둘 다 여유가 작다 — P7(GEX·진단 — 페이지 3 공개 지표 일부)이 공개 JS 를 더 쓰면 위 3 의 순서로 다시 정한다.
- 로그인 예산(90 KB)도 P6 로 여유가 1 KB 아래가 됐다 — 다음 단계에서 같은 결정이 필요할 수 있다.

## 갱신(2026-10-13 — P7 WRAP, 위 §3 의 규칙 '넘치면 실측 + 10%')

- P7 페이지 3(진단·GEX)을 붙인 뒤 실측: 공개 JS gzip **81,266 B**(예산 73,728 — 넘침, 페이지 3 청크 7,117 B — 공개판은
  공공지표 진단·이벤트만 그리고 나머지는 자물쇠), 로그인 **99,353 B**(예산 92,160 — 넘침, 페이지 3 진단·GEX·띠 칩).
- 결정: 기능을 빼지 않고 예산을 실측 + 10% 로 — 공개 **88 KB(90,112 B)**, 로그인 **107 KB(109,568 B)**. CSS 20 KB 그대로.
  `web/scripts/check-bundle.mjs` `BUDGET_GZIP`.
- 다시 볼 때: 공개 페이지 3 청크에 로그인 패널 본문(GEX·시장 진단 — 공개 등급은 자물쇠 길만 탄다)이 같이 실려 있다.
  p8_stock 의 `LOGIN_VALUE` 방식(빌드 모드로 로그인 모듈을 뺀다)으로 옮기면 공개 쪽이 수 KB 줄어든다 — P8 에서 예산이 다시
  모자라면 먼저 이것을 한다.


## 갱신(2026-10-14 — P8 WRAP, 위 'P7 WRAP' 의 '다시 볼 때' 처리)

- 공개 페이지 3 청크의 로그인 패널 본문(① 판정 띠·③ 시장 진단·④ GEX)을 p8_stock `LOGIN_VALUE` 방식으로 공개 번들에서
  뺐다(`web/src/pages/p3_diag.ts` `LOGIN_MOUNTS` — 공개판은 같은 틀 `verdictPanels`·`marketPanels`·`gexPanels` 의 자물쇠만,
  요청 0). 공개 페이지 3 청크 gzip 7.19 KB → 3.22 KB.
- 실측(P8 페이지 11·12 를 붙인 뒤, 같은 빌드): 공개 JS gzip **83,501 B → 79,276 B**(예산 90,112 B 안 — 여유 10.8 KB, 공개판
  페이지 11·12 는 자물쇠 틀만), 로그인 **121,256 B**(예산 109,568 B — 넘침: 페이지 11 규칙·편집기·성과, 페이지 12 백테스트·
  저널·포트폴리오·상관·추천, 쓰기 채널).
- 결정: 공개 예산 **88 KB 그대로**(줄이지 않는다 — P9 legacy 비우기 화면 이전 여유). 로그인은 같은 규칙(실측 + 10%)으로
  **131 KB(134,144 B)**. CSS 20 KB 그대로. `web/scripts/check-bundle.mjs` `BUDGET_GZIP`.
