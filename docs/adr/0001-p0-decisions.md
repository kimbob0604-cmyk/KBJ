상태: 확정(U1~U4) · 기본값(Q1~Q13, 실데이터 비교 후 바꿀 수 있음)

> **2026-10-08: Q1 의 마감 요약 시각(16:40)은 [ADR 0018](0018-post-close-1600.md) 이 16:00 으로 바꿨다**(사용자 결정 — 장 마감 뒤 텔레그램은 전부 16:00). 출처(KIS 당일 → 다음 영업일 KRX 대조)는 그대로다.

## 사용자 결정 (확정)

| # | 결정 | 반영 |
|---|---|---|
| U1 | KIS 앱키와 텔레그램 봇은 세 프로젝트가 **같이 쓴다** | 토큰 발급은 auth 서비스 한 곳(1분 1회), 앱키당 레이트리미터 하나. 발송은 notifier 한 곳. 수신은 notifier 웹훅 하나로 받아 명령·인박스로 나눈다(`getUpdates` 와 `setWebhook` 은 같은 봇에서 같이 못 쓴다) |
| U2 | 중복 브리핑은 **하나로 합친다** | 아침 브리핑 1회, 마감 요약 1회 |
| U3 | 실데이터 fixture·제3자 코드: **합성 데이터로 바꿔 공개** | 공개 등급 실데이터(DART·ECOS 한은 표·관세청·금투협 종합통계)와 직접 만든 코드·사전은 그대로 옮긴다. KIS·KRX·네이버·Yahoo 등 로그인 등급 실데이터와 개인 데이터(블루스카이 게시물, 노트, 원고, 구루 조사)는 같은 형태의 합성 데이터로 바꾸고 계산 검증 테스트는 유지한다. `rsm0kk` 유래(`monitor/bok`, `monitor/kr` 템플릿·사전·골든)는 옮기지 않고 P5에서 직접 다시 만든다 |
| U4 | 네이버 의존 기능은 **로그인 전용**, 데이터는 KRX·KIS로 바꾼다 | 네이버 스크래핑은 KBJ에서 쓰지 않는다. 대체 출처는 `docs/conflict_map.md` §1.13 |
