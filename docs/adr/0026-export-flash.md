# ADR 0026 — 수출 속보 반영(관세청 10일 잠정치 — 폴링 창·발표 당시/최신·열 변경·16:00 한 줄·공개 파일) (2026-10-13)

상태: **채택**(2026-10-13 — 초안 P6 묶음 FLASH, 번호·상태는 웨이브 3 WRAP 이 확정 — 아래 'WRAP 확정 메모').
근거: `docs/p6_design.md` §1.3·§3·§4.1·§5·§7, D-P6-6·7·8·11·12·13, 부록 A §25, ADR 0011(공개 브랜치 강제 푸시 1커밋),
ADR 0018(장 마감 뒤 발송은 16:00), 사용자 결정 2026-10-13(속보일 따로 발송 없이 16:00 마감 요약 한 줄, 원화 환산 없음,
관세청 공개 집계는 public-data 브랜치에만 — main·픽스처는 합성).
구현: `kbj/engines/trade/flash.py`, `kbj/engines/market/ribbon.py`(`export_flash` 칩), `kbj/services/api/readers/{trade_flash,
market}.py`, `kbj/services/public_export/trade_flash_json.py`, `kbj/reports/briefs/closing_brief.py`(`export_flash_line`),
`web/src/pages/p7/flash.ts`, `web/src/app/ribbon.ts`.

## 1. 맥락

- 관세청 10일 단위 잠정치(공공데이터포털 15157908·941·901·909)는 그 달 1일부터 구간 끝 날까지의 **누계**다. 공표는
  1·11·21일 무렵이지만 API 반영 시각·주말 규칙은 문서에 없다(probe §2.6, 실측 #6·#17·#55).
- 같은 구간 값이 나중에 정정될 수 있고(#6 ②), 10대 품목·국가 열 구성이 바뀌면 같은 열 번호가 다른 대상을 가리킨다.
- 장 마감 뒤 텔레그램은 16:00 한 번(ADR 0018) — 새 발송 종류를 만들지 않는다(D-P6-8).

## 2. 결정

1. **수집 창·데이터 키(COL — 이 ADR 은 정의만)**: 공표일과 그 뒤 이틀 09:00~17:40 20분 폴링, 데이터 키 `YYYYMM-n` 선점이
   done 이 되면 나머지 폴링은 건너뛴다. 작업 `trade.customs_tenday` 는 실측 전 `enabled: false`.
2. **발표 당시 대 최신**: 행마다 `first_usd`·`first_seen_at`(처음 본 값 — 저장소가 덮지 않는다)과 `usd`·`revised_at`(최신)을
   둘 다 둔다. 화면 표·YoY 는 **최신**, 상단 띠 칩·마감 요약 줄은 **발표 당시** 값의 YoY(분모 = 전년 같은 구간의 최신 값 —
   이미 굳은 값).
3. **YoY·기여도 정의**(metrics §25): `v(ym, seg) / v(ym−12, seg) − 1`, 10대 기여도 `Δvᵢ / Δv₀₀`. 전년 값 없음·0 은 None + 사유,
   **열 이름이 전년과 다르면 YoY·기여도 None**(사유 '열 이름 바뀜'). 0 으로 채우지 않는다. 누계가 앞 구간보다 작은 칸은 오류가
   아니라 notes 경고(정정 반영 중일 수 있다).
4. **열 구성 변경**: 어댑터가 `TenDayColumnsChanged` 로 그 종류 수집을 실패시키고 옛 값을 유지(D-P6-13). 엔진은 저장된 칸 이름을
   그대로 믿고 비교만 막는다.
5. **띠 칩**: `export_flash` 를 '준비 중(P6)' 목록에서 빼고 값 칩으로(공개 등급). 값 = 수출 품목 전체(열 00) 최신 구간의 발표 당시
   YoY, 기준 구간은 detail(`1~20일`), quality 는 원천이 ok 라도 `estimated`(잠정치). 값이 없으면 단계 표시 없이 사유만.
6. **16:00 마감 요약 한 줄**: ① 섹션 끝에 '수출 속보 11월 1~10일 220.0억 달러 · 전년 대비 +10.0% (관세청 잠정 · 발표 당시)'.
   창 = (전 거래일 16:00, 지금] 에 **처음 본** 구간만(여럿이면 가장 최근 하나). 공표일이 휴장이면 다음 거래일 마감 요약에 실리고,
   그다음 날은 다시 싣지 않는다. 재료가 아니라 덧붙임이라 없으면 줄이 없을 뿐 not_ready 가 아니다.
7. **공개 파일**: 칩은 `credit.json` 이 아니라 **`trade/ribbon.json`**(관세청 표만 읽는 모듈 — 금투협·ECOS 신용 칩 파일과 원천을
   섞지 않는다, 같은 칩 모양). 속보 표는 `trade/flash.json` 하나에 4종(로그인 응답과 같은 모양) — 상한 200 KB 에 맞춰 **최근
   6개월**(설계서의 10년은 칸 수가 상한을 크게 넘는다, 12개월도 약 250 KB). 더 긴 기간은 로그인 API(`months` ≤ 120).
   공개 내보내기 하루 4회(D-P6-7)는 등록부(FND·WRAP).
8. **공개 패키지는 엔진을 import 하지 않는다**(계약 ⑧) — 같은 정의를 `trade_flash_json.py` 에 따로 적고, 시험
   (`test_trade_flash_json.py`)이 엔진 값과 칸마다 대조한다.

## 3. 결과

- 장점: 정정·열 변경이 화면에서 숨지 않는다(발표 당시/최신 두 값, 사유 칸). 텔레그램 발송 횟수 증명(하루 1회 마감 요약) 유지.
- 비용: 공개판은 최근 6개월만. 정의가 엔진·공개 모듈 두 곳 — 대조 시험으로 묶었다.
- 남은 것: 실측 #55(주말 공표·반영 시각) 뒤 폴링 창 축소, #57 뒤 공개 상한 확정(10년 공개가 필요하면 종류별 파일로 쪼개는 안).

## WRAP 확정 메모(2026-10-13)

- 번호 0026 그대로 채택. 사용자 결정(2026-10-13 — 설계서 열린 질문 기본값 채택)과 어긋나는 곳 없음: 속보일 따로 발송 없이
  16:00 마감 요약 한 줄(Q4), 원화 환산 없음(Q8), 관세청 공개 집계는 public-data 브랜치에만(Q3 — main·픽스처는 합성).
- 값 기준을 `docs/metrics.md` §25 에 옮겼다: 칩·마감 요약은 발표 당시 값(`first_usd`), 분모는 전년 같은 구간의 최신 값,
  같은 달 누계가 앞 구간보다 줄면 값을 고치지 않고 notes 경고. 전월 같은 구간 대비(`mom`)는 WRAP 이
  `TradeFlashCell.mom` 칸을 더해 API·공개 `trade/flash.json` 에 싣는다.
- 띠 칩 파일은 `trade/ribbon.json`(신용 `credit.json` 과 원천이 달라 분리) — `manifest.FILE_CAPS`·
  `merge-public-data.mjs FILE_CAPS` 에 상한 4 KB 를 더했다.
- `trade/flash.json` 은 최근 6개월(`PUBLIC_MONTHS` — 200 KB 상한). 설계서 §7 의 '4종 × 10년'은 상한에 들어가지 않는다 —
  10년 공개는 종류별 파일로 쪼개거나 상한을 올려야 하며 실측 #57 뒤 정한다.
- 증명: `tests/sim/test_flash_day.py`(§0.3 ①~⑥ — 운영 등록부의 `trade.customs_tenday` 한 줄을 이 사본에서만 켜고 실제
  수집 처리기·가짜 관세청·가짜 시계로 11-11 10:47 공표 → 11:00 수집 → API·띠 칩·공개 파일·16:00 한 줄, 토요일 공표 →
  월요일 16:00, 월초 말일 구간, 하루 늦은 공표, 열 구성 변경 → 그 종류만 실패·옛 값 유지, 같은 키 재폴링 0).
- 운영에서 `trade.customs_tenday` 는 **꺼진 채**다 — 키 수령·실측 #6·#17·#55 뒤 켠다.
