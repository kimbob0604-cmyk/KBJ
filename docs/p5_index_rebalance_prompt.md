# P5 2차 묶음 IDX — 패시브 지수 정기변경(편입·편출) 예측 — 작업 프롬프트

> 2026-10-13 사용자 요청: "MSCI 같은 거대 패시브 자금이 몰릴 종목을 예측하는 시스템 — 패시브 자금(지수)별로 편입·편출 종목을
> 알고리즘에 따라 계산해서 대시보드에 나타내는 것까지. 전체 대시보드 양식이 깨지지 않고 유지되어야 한다."
> 이 문서는 **P5 본 실행이 커밋된 뒤** 별도 묶음(P5 2차 IDX)으로 그대로 실행하는 지시다. 검증 근거 §1, 넣는 자리 §2.

---

## 0. 만들 것

1. **지수별 정기변경 예측 엔진** — 지수마다 규칙 모듈 하나(순수 함수, 시계 주입). 입력: 기준일 시총·유동시총·거래대금·업종·상장일·현 구성종목.
   출력: 종목별 `편입 후보 / 편출 후보 / 경계 / 유지`, 근거 수치(컷오프 대비 괴리율, 필요 주가 상승률), 예상 패시브 매매 규모.
2. **대상 지수(1차):** MSCI Korea(Standard) · KOSPI200 · KOSDAQ150. **2차(같은 틀, 설정만 더함):** FTSE(GEIS) · KRX300.
3. **화면(기존 양식 안에서만 — 새 페이지를 만들지 않는다):**
   - 페이지 10(ETF)에 패널 묶음 **'지수 정기변경'** 하나: 지수 탭 · 일정 띠(기준일·발표·리밸런싱·효력일과 D-day) · 편입 후보 표 · 편출 후보 표 · 컷오프 추정치와 근거.
     표의 열은 사용자 예시와 같다: 종목 · 시가총액 · 유동시총 · 유동비율 · 시총 컷오프 괴리율 · 유동시총 컷오프 괴리율 · 조건 충족(O/X) ·
     필요 주가 상승률(시총 기준·유동 기준 중 큰 쪽) · 예상 패시브 매수(억) · 일평균 거래대금 대비 배수.
   - 페이지 5(일정) 캘린더에 지수 이벤트 줄, 페이지 8(종목 상세) 머리에 배지 한 줄(예: `MSCI 편입 후보 · 필요 +12.4%`).
   - P3·P4 의 패널·상태 표시(quality·추정·자물쇠)·테마·모바일 규칙을 그대로 쓴다. 새 색·새 글꼴 없음.
4. **텔레그램은 이번 묶음에 넣지 않는다**(결과 발표일 알림 등은 P8 규칙 알림에서 — ADR 0018 의 16:00 규칙 유지).

## 1. 검증 — 규칙·데이터 출처와 한계 (2026-10-13 확인)

### 1.1 MSCI
- 정기 리뷰 연 4회(2·5·8·11월). 발표는 한국시간 해당 월 중순 새벽, 효력은 다음 달 첫 영업일 즈음, 패시브 매매는 효력일 직전 영업일 종가.
  **날짜는 MSCI 가 해마다 공표하는 일정표로 설정에 적는다**(계산으로 추정하지 않는다) — `config/index_reviews.yaml`.
- 편입·편출은 'Interim Market Size-Segment Cutoff'(컷오프) 대비 배수로 판정한다.
  - 공개된 옛 방법론 요약(2014)은 신규 편입 조건이 **시총 ≥ 1.8 × 컷오프 그리고 유동시총 ≥ 1.8 × ½ 컷오프**다.
  - 사용자 요약(리포트)은 1.5× · ½ 를 쓴다.
  - 하나증권 표는 편입 유동 컷오프 = 컷오프의 ⅓, 편출 컷오프를 따로 쓴다 → **배수는 문서마다 다르다.**
  - **모든 배수·유지 기준(⅔·⅓ 등)은 설정값으로 두고, 현행 MSCI GIMI 방법론(2026-03판) 원문과 대조해 확정한다 [확인 필요].**
    설정에 출처·확인일을 함께 적는다.
- **컷오프는 MSCI 가 공표하지 않는다** → 엔진이 방법론의 시장 커버리지 방식으로 추정한다. 추정 근거·구간을 화면에 보이고,
  사용자가 증권사 추정치를 입력하면(로그인 화면) 그 값으로도 같이 계산한다(두 결과를 나란히 — 어느 쪽인지 표시).
- **유동비율(FIF) 반올림 — 시점에 따라 규칙이 다르다:**
  - MSCI 가 2025-02 에 확정한 새 규칙(유동비율 > 25% → 2.5% 단위, 5~25% → 0.5% 단위, < 5% → 0.1% 단위 반올림,
    직전 FIF 대비 같은 폭의 완충 ±2.5·±0.5·±0.1%p)은 **2026-05 리뷰부터 적용**됐다
    (사용자 요약의 '2025-05 리뷰부터' 와 다르다 — MSCI 발표 기준). 지금(2026-10)은 새 규칙이다.
  - 그 이전 리뷰를 되짚을 때(백테스트)는 옛 규칙(15% 초과는 5% 단위 올림, 미만은 1% 단위 반올림)을 쓴다.
  - 규칙은 리뷰 날짜로 고른다. 경계값은 [확인 필요].
- 외국인 지분 한도(FOL) 종목은 FIF 를 한도 여유로 다시 줄인다(방법론 §FOL) [확인 필요] — 통신·항공·방송 등. 한도 표는 설정.
- **현 구성종목 목록은 MSCI 독점 자료다** → 레포·공개 빌드에 넣지 않는다.
  - 원천은 둘이다. (a) 사용자가 VM 에 올리는 목록(로그인 등급). (b) MSCI 보도자료의 리뷰 결과 공지(편입·편출 이름)를 분기마다 사람이 반영한다.
  - 레포에는 합성 목록만 둔다.

### 1.2 KOSPI200 · KOSDAQ150 (KRX)
- 정기변경 연 2회(6·12월). 심사기준일·발표일·효력일(선물옵션 만기 다음 거래일)은 KRX 공지로 설정에 적는다.
- 규칙(업종별 누적 시총 비중·거래대금 순위·기존 종목 완충 90%/110%·신규 상장 특례·관리종목 제외 등)은 **KRX 지수 산출 방법론 원문을 설정·규칙 모듈로 옮긴다 [확인 필요]**.
  유동비율은 KRX 기준(지수용 유동주식수) — 출처는 KRX OpenAPI 에 있는지 [실측 필요], 없으면 DART 지분 공시로 추정하고 '추정' 표시.
- 패시브 규모: 국내 ETF 는 KBJ 가 이미 가진 ETF 순자산(P3 `etf.collect`) 중 추적지수가 KOSPI200·KOSDAQ150 인 것의 합 + 설정의 비ETF 추정치(연기금 패시브 등 [확인 필요]).

### 1.3 공통 데이터 (이미 있는 것)
- 시총·상장주식수·거래대금·업종: P3 KRX 일별(`krx.daily`).
- 최대주주·특수관계인·자기주식·5% 대량보유: P4 DART 지분 공시 파서 → MSCI 식 전략적 보유 제외로 유동비율 추정.
  정부·연기금·자사주·임원 보유를 어떻게 다루는지는 지수마다 다르니 규칙 모듈이 고른다.
- 신규 상장·분할·합병·상장폐지: KRX·DART 사건 → 조기 편입·대체 편입 후보.

## 2. 넣는 자리 — P5 2차 묶음 IDX (이유)

- 기대는 것이 P3(KRX 일별·ETF 순자산)·P4(DART 지분·페이지 8)·P5(페이지 10 ETF 묶음·페이지 5 캘린더 — MAC 묶음)에 다 있다.
  그래서 **P5 본 실행이 커밋·CI 녹색이 된 뒤** 바로 돈다(P6 전). 지금 도는 P5 실행에 끼우지 않는다 — 페이지 10·5 를 동시에 고치면 충돌한다.
- 화면은 새 페이지를 만들지 않고 페이지 10 의 패널 묶음 하나 + 5·8 의 한 줄씩이다(MD6 13페이지 구조·미니맵·스와이프 그대로).

## 3. 만드는 순서

1. **방법론 정리**(`docs/metrics.md` 새 절 + `config/index_reviews.yaml`): 지수별 일정·배수·완충·반올림 규칙(시점별)·패시브 규모 추정식.
   모든 숫자에 출처·확인일·[확인 필요]. 사용자 예시의 열 정의(괴리율·필요 상승률)를 수식으로.
2. **엔진**(`kbj/engines/index_review/` — 지수별 모듈 + 공통 컷오프·유동비율·필요 상승률·패시브 규모):
   순수 함수, 시계·설정 주입. 필요 상승률 = max(시총 조건, 유동 조건)을 맞추는 최소 주가 변화(유동비율이 반올림 경계를 넘는 경우 포함).
3. **저장**: 마이그레이션 새 번호 — `prv_index.constituents`(지수·종목·기간, source 'user'·'press' 구분), `prv_index.review_calendar`,
   `prv_index.predictions`(리뷰·기준일·종목·판정·근거 JSON·컷오프 추정·as_of·quality), `prv_index.passive_aum`.
4. **작업**(`config/jobs.yaml`): `index.predict` 장 마감 뒤 매일(리뷰 기준기간 중엔 기준일 값으로 고정), `index.calendar` 설정 → 표.
   16:00 발송 묶음과 겹치지 않게(ADR 0018). 구성종목 목록이 없으면 '목록 없음' 상태로 돌고 예측을 내지 않는다(지어내지 않음).
5. **API·웹**: `/api/index-review?index=&review=`, `/api/index-review/stock/{code}`. 페이지 10 패널 묶음·5 캘린더 줄·8 배지.
   openapi·types 재생성. 로그인 빌드 전용(공개 빌드·내보내기 제외 — 구성종목·컷오프 추정이 들어간다).
6. **백테스트 검증(로그인·로컬)**: 사용자가 과거 구성종목·발표 결과를 VM 에 두면 `python -m kbj.services.engine.index_review backtest`
   가 과거 리뷰를 다시 계산해 적중·놓침·오탐 표를 낸다. 레포 시험은 합성 세계로만.

## 4. 시험

- **엔진 속성 시험:** 반올림 규칙 경계(25%·5%·15%, 리뷰 날짜에 따른 규칙 선택), 완충(직전 FIF ±폭 안이면 유지), 배수 경계(같음·직전·직후),
  필요 상승률 = 그만큼 오르면 정확히 조건을 넘는다(역산 검증), 컷오프 추정이 단조(시총이 오르면 순위·판정이 나빠지지 않는다).
- **골든(합성):** 합성 시장 50~300종목·합성 구성종목으로 3개 리뷰 예측 → 고정 기대값(p5_world 와 같은 고정 시드).
- **사용자 예시 재현(합성 숫자):** 표의 괴리율·필요 상승률 계산식이 사용자 예시 열 정의와 같다(값은 합성).
- **API·웹:** 라우트 시험, vitest(지수 탭·D-day 띠·빈 목록 상태·'추정' 표시·필요 상승률 정렬), 공개 번들에 없음(check-bundle).
- **공통 완료 명령** + 메인의 병렬 전체 검사(kbj_verify_all.sh).

## 5. 완료 기준

- 합성 세계에서 MSCI·KOSPI200·KOSDAQ150 각 1개 리뷰의 편입·편출 후보가 계산되어 페이지 10 패널에 그려지고, 5·8 에 한 줄씩 보인다(다른 패널·페이지 회귀 없음 — 데모 스크린샷 콘솔 오류 0).
- 반올림·배수·완충·필요 상승률 속성 시험 녹색, 규칙의 모든 숫자가 설정 한 곳에 출처와 함께 있다.
- 구성종목·컷오프 추정·예측은 로그인 등급 — 공개 빌드·내보내기·레포 픽스처에 실자료 0.
- [확인 필요] 항목(현행 MSCI 배수·KRX 방법론·FOL·패시브 규모)은 probe_results·설정 주석에 남고, 사용자가 확인값을 넣으면 그대로 바뀐다.
