# KBJ — 국장 터미널 계획서 (v0.2, 2026-10-06)

> 대상 시장을 **미국에서 한국으로** 바꿔 v0.1을 다시 쓴 계획서다.
> 두 사이트를 참고해 기능만 국장판으로 바꿔 구현한다. 디자인, 문구, 리포트, 데이터는 가져오지 않는다.
> - **md6.today**: 미국 시장 실시간 대시보드
> - **badonion.co.kr**: 25개국 수출입·HS코드 분석
>
> **[결정 필요]**: 착수 전에 사용자가 정할 것. 정하지 않으면 적힌 기본값으로 간다.
> **[확인 필요]**: 실측이나 약관 확인이 끝나기 전의 가정.

## 0. 한 줄 정의

**KBJ = 국장 실시간 대시보드(MD6의 국장판) + 수출입·펀더멘털 분석(BadOnion의 국장판) + GEXLAB 옵션 레벨.**
장중에는 켜 두고 시장 흐름을 보고, 장후와 월초에는 수출입·실적 흐름으로 종목을 고르는 도구다.

**미장판(v0.1)과 다른 점:** 국장은 이미 만든 자산이 많아 새로 시작하지 않는다.

| 가져올 자산 | 쓰는 곳 |
|---|---|
| GEXLAB(Python) | KIS·KRX 클라이언트, 레이트리미터·토큰 관리, KRX 거래 캘린더(야간·휴장·만기), TimescaleDB 스키마·저장, 서비스 골격(scheduler·poller·ws-gateway·engine), GEX 엔진, CI |
| ETF-Traker·국장 신고가 보드 | 52주 신고가 집계 |

그래서 v0.1의 Cloudflare/TypeScript 대신 **Python 백엔드(GEXLAB 재사용) + 정적 프런트**를 기본값으로 한다.

## 1. 참고 사이트 기능 요약 (2026-10-06 공개 페이지 기준)

### 1.1 MD6 (미국 대시보드) — v0.1 §1 요약
- **상단 띠**: 세션 카운트다운, FOMC 확률, 기술주 쏠림(TTG), 소비재 대 필수재(CONS), 시장폭(BRD), 하이일드(HY), 미국 대 해외(GTG)
- **뉴스·채팅·방문자**: 다국어 헤드라인(링크만), 익명 채팅, 익명 탭 집계
- **시장**: 섹터 히트맵, 경제 캘린더, 지수·종목·환율·채권·크립토, 매크로 발표치, 시총 트리맵, 대형주 실적 일정
- **진단**: 종합 판정과 이벤트 표시, 위 지표들의 상세와 상태 구간, 공포탐욕, 내부자 거래
- **차트·커스텀 위젯**, 테마 5종, 모바일·PWA

### 1.2 BadOnion (수출입 분석, 로그인 유료형)
- **무역 데이터 분석**
  - 25개국 HS코드별 월별 수출입 시계열: 금액, 중량, 단가, YoY, 3개월 평균
  - 급등 품목 탐색, 상관분석, 트리맵·히트맵
- **국가별 조회**: 품목 × 상대국 표, 상대국 비중, 품목 동향, 엑셀 다운로드
- **종목 맵핑**: 상장 종목과 HS 품목을 연결한다. 무역 흐름과 회사 매출을 겹쳐 보는 매출 대조, 트렌드 랭킹
- **기업 재무 대시보드**: NASDAQ-100·S&P 500의 손익계산서, 매출 세그먼트, 주가
- **PPI 모니터링**: 미국·한국·일본·중국 생산자물가 YoY 비교
- **리포트**
  - 월간 데이터 리뷰: 국가별 월 수출
  - 실적 프리뷰: 무역 데이터와 피어 월매출로 실적 추정
  - 메모리 가격 주간
- **데이터 범위**: 25개국, HS 6자리 이상, 5년 이상, 월 1회 갱신. 한국어·영어

## 4. 결정할 것

| # | 항목 | 기본값 | 이유·대안 |
|---|---|---|---|
| D1 | 레포 | 새 비공개 레포 `KBJ`. GEXLAB의 `core/`·`data/`·`services/`·`db/`를 공유 패키지로 옮기거나 하위 모듈로 가져온다 [결정 필요: 복사 대 공유] | GEXLAB과 함께 유지하려면 공유 패키지가 낫다. 빨리 가려면 복사한다 |
| D2 | 실행 환경 | **Python(FastAPI) + TimescaleDB + Redis(GEXLAB 그대로)**, 프런트는 정적(Vite·TypeScript), **서울 VM 1대** | GEXLAB 자산 재사용. 장중 상시 수집은 VM이 필요하다 |
| D3 | **공개 범위 (가장 중요)** | **비공개(본인 전용)로 시작** | KIS는 제3자 제공 불가, KRX Open API는 원천 데이터 재배포 금지 → **원시세(현재가·호가·체결)는 공개 화면에 못 낸다.** 공개하려면 코스콤·KRX 정보데이터 유료 라이선스나 증권사 제휴가 필요하다. 반대로 관세청·DART·ECOS·통계청은 공공데이터라 출처를 밝히면 공개 가능하다 |
| D4 | 공개 시 분리 | 공개판은 **수출입·재무·매크로·계산 지표만**, 원시세 위젯은 로그인한 본인만 | D3에 따라 |
| D5 | 무역 데이터 범위 | 1단계 한국만, 2단계 대만·일본·중국·미국 | 25개국은 국가마다 수집기가 달라 비용이 크다 |
| D6 | 종목 맵핑 범위 | 처음엔 관심 종목 50~100개를 직접 매핑 | 핵심 자산이라 품질이 우선이다 |
| D7 | 리포트 자동 생성 | 2단계 이후, 초안만 만들고 사람이 검토 | LLM 비용, 사실 검증 |
| D8 | 메모리 가격 | 제외(유료) | 대체: 국내 증권사 공개 자료 수동 입력 |
| D9 | 뉴스 | 국내 경제지 RSS 헤드라인 + DART 공시 | 기사 본문은 저장하지 않는다 |
| D10 | 채팅·방문자 | 제외(공개할 때 재검토) | 관리 부담 |

## 7. 단계 (Phase)

각 단계는 **완료 기준을 모두 채우면** 다음으로 넘어간다.

### P0 — 결정·실측 (2~3일)
- D1~D10을 확정한다.
- **관세청 API 실측** [확인 필요 해소]
  - 품목별·국가별 월간 수출입: HS 자릿수, 기간, 호출 한도
  - 10일·20일 잠정치가 품목 단위로 나오는지
  - 시군구 품목 데이터가 있는지
- DART OpenAPI 키 실측: 재무제표, 공시 목록, 잠정실적 공시 유형, 소유보고
- ECOS·KOSIS·KOFIA 시리즈 ID 확정: 기준금리, 국고 3·10년, 회사채 AA-·BBB-, PPI, 수출입물가, 고객예탁금, 신용잔고
- KRX 업종지수와 52주 신고가 데이터 경로 확인(ETF-Traker 보드 코드 재사용)
- 공개 범위(D3)를 정한다. 공개한다면 원시세 라이선스 견적을 받는다.
- **완료 기준:** `docs/probe_results.md`에 출처별 표가 있고, D1~D3가 확정돼 있다.

### P1 — 뼈대·GEXLAB 이식 (3~4일)
- 레포 구조. GEXLAB 공유 모듈(캘린더, KIS·KRX 클라이언트, 저장, 서비스 런타임)을 가져오고 CI를 붙인다.
- FastAPI 골격, 프런트 셸(페이지 스와이프, 테마, PWA, 한국어·영어)
- **완료 기준:** GEXLAB 테스트가 KBJ 레포에서도 통과한다. 빈 페이지 6개가 PC와 모바일에서 넘겨진다.

### P2 — 시장·수급 (4~6일)
- 지수, 선물(주야간), VKOSPI, 환율, 금리, 업종 히트맵, 코스피200 트리맵
- 투자자별 수급, 프로그램매매, 시장폭(신고가 포함), 신용·예탁금·공매도
- 상단 띠 1차
- **완료 기준:** 장중 1시간 수집에서 결측이 없다. 야간 전환이 맞다. 출처 장애 때 stale로 표시된다.

### P3 — 매크로·일정·공시 (4~5일)
- ECOS·KOSIS·KOFIA 매크로(직전값, 다음 발표일), 미국 주요치
- 경제 캘린더(한국·미국·금통위·FOMC·만기)
- DART 공시 피드, 잠정실적 → 실적 일정, 소유보고·자사주
- **완료 기준:** 발표 다음 날 자동으로 갱신된다. 잠정실적 공시가 나오면 5분 안에 반영된다.

### P4 — 진단 지표 (4~6일, 명세 먼저)
- `metrics.md`에 각 지표의 공식, 상태 구간, 품질 규칙을 먼저 쓴다.
  - 반도체 쏠림, 경기민감 대 방어, 시장폭, 신용스프레드, 한국 대 글로벌
  - 수급 진단, 국장 공포탐욕, 금통위 경로
  - 종합 판정과 이벤트 표시
- GEX 레벨 위젯은 GEXLAB engine 출력을 그대로 쓴다.
- **완료 기준:** 지표마다 명세 테스트와 경계 테스트가 있다. 과거 날짜로 다시 계산해도 결과가 같다.

### P5 — 수출입 1단계: 한국 (6~8일)
- 관세청 월간 수집(5년 백필), 10일·20일 속보, 지역별(가능하면)
- 탐색기: 품목, 국가, 지역, 급등, 단가 대 물량, 트리맵, CSV
- **완료 기준:** 1일·11일·21일 발표 당일 자동으로 반영된다. 금액·중량·단가 합계가 공식 발표 합계와 맞는다(오차 0).

### P6 — 기업·매핑 (5~7일)
- DART 재무(분기, 5년), 부문 매출, 주가
- **종목 ↔ HS·지역 매핑표**(관심 종목 50~100개), 무역 흐름 대 매출 겹쳐 보기, 시차 상관, 트렌드 랭킹
- **완료 기준:** 매핑 종목마다 "품목 수출 YoY 대 분기 매출 YoY" 차트가 나온다. 매핑표 검증 테스트(존재하는 HS코드·종목코드)가 통과한다.

### P7 — 수출입 2단계·피어 (선택)
- 대만·일본·중국·미국 무역 데이터, 대만 피어 월매출, 한국과 주요국 PPI 비교

### P8 — 리포트·공개 (선택)
- 월간 수출 리뷰 초안 자동 생성(D7)
- 공개판(D4): 이용약관, 개인정보, 출처 표기, 원시세 제외 확인
- 장중 무중단 1주
