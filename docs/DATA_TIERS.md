# KBJ — 공개/로그인 데이터 등급표 (v0.3 보완, 2026-10-06 · 약관 확인 반영)

> 이 문서는 KBJ v0.3 계획서의 §6(포트폴리오)과 D3(공개 범위)을 **대체**한다.
> 원칙은 하나다. **애매하면 로그인 쪽에 둔다.** 나중에 약관을 확인해 공개로 올리는 건 쉽지만, 공개했다가 내리는 건 늦다.
> 등급은 실행 중에 검사하지 않는다. **저장소, 빌드, 서버를 처음부터 나눠서** 섞일 수 없게 만든다(§3).

## 2. 기능별 등급

로그인하면 **모든 기능**을 본다. 아래는 로그인하지 않았을 때 보이는 범위다.

|---|---|---|

## 3. 나누는 방법 — 섞일 수 없게 구조로 분리

| 층 | 공개 | 로그인 |
|---|---|---|
| **서버** | 없음. 정적 사이트(GitHub Pages) | 서울 VM의 FastAPI + 로그인(본인 계정 1개) |
| **데이터 전달** | scheduler가 공개 등급 데이터만 `public/*.json`으로 내보내고 Pages에 배포 | VM API가 DB에서 바로 응답 |
| **DB** | 공개 JSON은 `public` 스키마에서만 만든다 | `public` + `private` 스키마 모두 |
| **수집기 위치** | `kbj/data/public/`(dart·ecos·kosis·customs·fsc_kofia_stats·fsc_retail_bond·fred_gov·rss) | `kbj/data/private/`(kis·krx·fsc_stock_price·fsc_index_price·yahoo·naver_search·etf_issuers·consensus) |
| **프런트** | 같은 SPA. 공개 빌드는 공개 JSON만 읽고, 로그인 위젯은 자물쇠로 표시 | 같은 SPA. 로그인하면 VM API를 읽는다 |

- 공개 내보내기 코드는 `kbj/data/public/`과 `public` 스키마만 import할 수 있게 **폴더 구조로 막는다.** 실행 중 검사가 아니라 애초에 경로가 없게 한다.
- 공개 사이트에는 로그인 API 주소조차 넣지 않는다. 로그인 화면은 VM 도메인에서만 열린다.

## 4. 공개 레포에 올리는 것과 올리지 않는 것

**`.gitignore`로 처음부터 제외한다**(검사가 아니라 아예 커밋 대상이 아님).
- `.env`, `*.key`, `secrets/`
- `data/`, `state/`, `probe_out/`, `runs/`, `*.sqlite`, `*.db`
- `fixtures/real/`
- 로그인 등급 원본 응답 녹화(`raw/`)

**테스트 데이터**
- 로그인 등급 출처(KIS·KRX 등)의 테스트는 **합성 데이터**로 만든다(`fixtures/synthetic/`).
- GEXLAB의 실제 옵션 체인 스냅샷과 raw 녹화 골든은 KBJ로 옮길 때 합성 체인으로 다시 만든다. 계산 검증은 그대로 유지한다.
- 공개 등급 출처(DART·ECOS·관세청·금융위 종합통계·소매채권)의 실데이터 fixture는 올려도 된다. **금융위 주식·지수 시세는 안 된다.**

**기존 레포 처리**
- stock-dashboard, ETF-Traker, GEXLAB은 공개로 바꾸지 않는다(이력에 키·데이터가 있을 수 있다).
- KBJ는 새 레포에서 깨끗하게 시작한다.
- 옛 레포에서 키가 커밋된 적이 있다면 키를 재발급한다.

**MD6 디자인**
- 스타일은 보고 직접 다시 만든다(CSS 토큰, 레이아웃).
- MD6의 CSS·JS 파일, 로고, 이미지, GIF는 복사하지 않는다.

## 5. 계획서 단계에 반영

- **P0:** 약관 3건은 확인을 마쳤다(2026-10-06, §1의 ✅·❌ 표시). 남은 것은 ECOS 약관 본문 한 번 읽기뿐이다. 공공데이터포털 키를 신청할 때 관세청 5개, 금투협 종합통계, 소매채권 데이터셋을 함께 신청한다. 운영계정의 트래픽 증가는 활용사례를 등록하면 된다.
- **P1:** `data/public` / `data/private` 폴더, `public` / `private` DB 스키마, 정적 공개 빌드 + VM 로그인 API 두 갈래를 **처음부터** 만든다. `.gitignore`도 이때 확정한다.
- **P3:** 신고가 보드는 로그인판으로만 만든다(KRX·KIS). 공개판 첫 화면은 수출입 탐색기와 매크로·신용 지표로 시작한다.
- 공개 레포라 GitHub Actions는 무제한 무료다.
