# 화면 감사 — 깨진 패널·종목 매핑·안 바뀌는 값(2026-10-27)

> 사용자 요청: 대시보드에서 깨진 패널, 종목 코드↔이름·데이터 매핑이 틀리게 보이는 곳(특히 페이지 7 수출입 '종목' 탭,
> 페이지 8 종목 상세, 페이지 9 테마, 페이지 10 ETF), 갱신이 안 되는 곳을 찾아 고친다.
> 실제 대시보드는 사용자 맥에서만 돈다 — 이 감사는 **합성 데모**(`bash scripts/demo.sh --shots DIR --at close|intraday`,
> `scripts/demo_server.py`)와 직접 짠 Playwright 드라이버(탭 누르기·종목 열기·빠른 종목 바꾸기·이상 글자
> 'NaN'·'undefined'·'[object Object]'·'Infinity' 검사·4xx/5xx 요청 수집)로 했다. 실데이터로만 가릴 수 있는 것은
> **맥 확인 필요**로 적었다.
> 갱신 주기·응답 캐시(폴링)는 다른 작업이 맡아 여기서 고치지 않았다(아래 '넘긴 것').

### 공통 1 — '아직 없음' 안내가 두 번·빨간 오류로

`web/src/ui/panel.ts` 에 `failText(err, hint)`·`isNoDataError(err)` 를 두었다. 404 `no_data` 는 서버 문구(이미 '아직 없음 — <작업 시각>')만,
서버 문구가 없는 실패(공개 파일 404·500·형식 오류)만 '오류 — 힌트'. 쓰는 곳: 페이지 3(diag·gex), 6(시리즈·탭 목록), 7(failNote).
페이지 1·8·9·11·12·13 은 원래 `serverMessage` 를 먼저 쓰고 있었다.
