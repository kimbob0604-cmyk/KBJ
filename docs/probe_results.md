# P0 실측·명세 — 공공데이터

> **키 없이 공개 문서로 조사한 명세. 키를 받은 뒤 실호출로 확인할 항목은 [실측 필요]**
>
> - 조사일: 2026-10-06. 공공데이터포털 상세 페이지(`https://www.data.go.kr/data/<ID>/openapi.do`)와 첨부 참고문서(docx·xlsx), 한국은행 ECOS 개발 가이드·이용약관, KOSIS 공유서비스 개발 가이드·공지·약관을 읽었다.
> - ECOS 통계표·항목 코드는 개발 가이드에 실린 **공개 예시 키**(요청 1회 10건 제한)로 `StatisticTableList`·`StatisticItemList`를 불러 확인했다. 개인 키는 쓰지 않았다.
> - 표기: **[실측 필요]** 키 받은 뒤 실호출로 확인 · **[추정]** 문서에 직접 근거가 없는 판단 · **[결정 필요]** 사용자가 정할 것 · **[제안]** 이 문서의 권고.
> - 근거 표기: `DG:<ID>` = 공공데이터포털 상세 페이지, `DOC:<ID>` = 그 페이지의 참고문서, 소스 경로는 `p0src/<레포>/<경로>:<줄>`(읽기 전용 스냅샷 `/home/user/p0src`). 내려받은 원문 목록은 §8.
> - 키·토큰 값은 이 문서 어디에도 없다. 환경변수는 이름만 적었다.
