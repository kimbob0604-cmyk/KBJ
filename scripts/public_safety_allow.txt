# 공개 안전 검사 허용 목록 — scripts/check_public_safety.py
#
# 형식: 경로 | 규칙[,규칙…] | 사유
# - 경로: 레포 루트 기준 posix 경로. fnmatch 패턴을 쓸 수 있다(`*` 는 `/` 도 넘는다 — 좁게 쓴다).
# - 규칙: 검사 규칙 이름(쉼표로 여러 개). `*` 는 모든 규칙 — 합성 데이터 파일처럼 꼭 필요할 때만.
# - 사유: 필수. 왜 오탐인지, 무엇으로 확인했는지 적는다. 사유 없는 줄은 검사 전체를 실패시킨다.
# 실제 비밀값을 허용 목록으로 덮지 않는다 — 지우고 키를 재발급한다(DATA_TIERS §4).
